# BOSHX Playing Cards

Multiplayer playing cards with a 3D shuffling machine. No download: it runs in the browser and installs as an app (PWA).

**Play:** https://bhavfy.github.io/boshx/

## How to play
1. Open the link on your phone, pick a name.
2. Choose *Playing Cards*, create a room and share the room link or 5-letter code.
3. Friends join with the link, then the host starts the game. Each turn has a timer; if you are too slow a bot plays for you.
4. Chat and voice are in the room. Add to Home Screen to install.

## Notes
This repo holds only the frontend (static files). The game server (rooms, chat, accounts) runs separately and allows requests from this site.
